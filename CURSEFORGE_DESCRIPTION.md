# Just Storage Panel

Just Storage Panel is a focused storage-and-crafting mod for Minecraft 1.21.1 on NeoForge. Instead of filling the game with a large tech tree, complex power systems, or dozens of new machines, it solves one very practical survival problem: keeping your storage organized and easy to use.

The mod is built around exactly three blocks:

- Access Panel
- Crafting Panel
- Logic Cable

That limited scope is the main idea of the project. Players get a clean, compact item network that is easy to understand, quick to build, and useful from early storage rooms all the way to larger multiplayer bases.

## What Players Can Do With It

In normal Minecraft play, storage often becomes messy very quickly. A few chests turn into rows of chests, then barrels, then modded inventories, and eventually players spend more time searching for materials than actually building or crafting.

Just Storage Panel changes that experience by letting players connect multiple inventories into one searchable network.

With an Access Panel, a player can:

- view the combined contents of connected inventories in one screen
- insert items into the network without opening each chest manually
- extract items from the same interface
- browse large storage systems through pages instead of checking containers one by one
- search for items by name to find materials quickly

In practice, this means less time walking between containers and less frustration when working on large projects. Instead of remembering where every stack was stored, players can open one panel, search for what they need, and continue building.

## Access Panel

The Access Panel is the main storage terminal of the mod.

It turns connected inventories into a single item overview. A player can stand in front of one block and immediately see what is available across the whole connected network. This makes routine tasks much faster:

- gathering building blocks before a project
- checking whether materials are already in storage
- dropping off mining loot after a cave run
- pulling out crafting ingredients without opening many separate inventories

The interface is designed to be practical during real gameplay. The item list is larger than a basic chest view, stack counts are shown clearly, and the panel supports scrolling, paging, and searching. The result is a storage screen that feels useful even when the network grows far beyond a small starter setup.

## Crafting Panel

The Crafting Panel expands the Access Panel idea into a crafting terminal.

It includes a 3x3 crafting grid while still giving access to the connected storage network. This changes the player's experience in an important way: recipes no longer require pulling all ingredients into the inventory first and then moving them around manually.

Instead, players can:

- search the network for ingredients
- pull missing items directly from connected storage
- craft from one central terminal
- return to building or processing items without repeated chest management

For bases with a lot of materials, this makes crafting feel faster, cleaner, and much less repetitive.

## JEI Integration

When JEI is installed on the client, Just Storage Panel supports recipe transfer into the Crafting Panel.

This improves the user experience even more for modded survival and modpack play:

- players can look up a recipe in JEI
- send the recipe layout directly into the Crafting Panel
- see immediately which ingredients are available in the connected network
- use a dedicated JEI button from the panel interface for quicker recipe lookups

This makes the mod especially comfortable in kitchensink modpacks or large bases where players craft many different items and do not want to memorize every recipe.

## Logic Cable

Logic Cable is the block that connects the network together.

Its purpose is simple: link panels to inventories and other supported storage endpoints without requiring a complicated controller setup. Players can use it to build a compact and readable storage system that fits naturally into workshops, storage basements, crafting rooms, and multiplayer bases.

Because the cable connects the system visually and functionally, it also helps the mod feel grounded in the world. The network is not abstract or hidden behind menus alone; players actually build and expand it as part of their base.

## Works With Existing Storage

The network is designed to interact with inventories that expose compatible item handlers, which means players can keep using their existing storage blocks instead of rebuilding their whole base around a new system.

The mod also includes targeted support for Sophisticated Storage controller-style access blocks such as controller, storage IO, storage input, and storage output. In gameplay terms, this improves compatibility and makes it easier to add Just Storage Panel to an already established storage setup.

That is important for players who want a lightweight terminal experience without replacing the storage mods they already enjoy.

## Multiplayer Experience

Just Storage Panel is suitable for modded multiplayer environments where several players share storage rooms, workshop areas, or community bases.

In multiplayer, the value of a central storage interface becomes even more obvious:

- shared resources are easier to find
- less time is wasted searching through group storage
- crafting stations become more convenient for all players
- large communal bases stay more organized

Because the mod keeps the workflow straightforward, it works well both for solo survival players who want cleaner storage and for servers that want a practical shared network without excessive complexity.

## Why This Mod Feels Different

Many storage mods focus on scale, automation, or full digital storage replacement. Just Storage Panel takes a more focused approach.

Its identity comes from three things:

- a small and understandable block set
- a clear improvement to everyday storage and crafting tasks
- a lightweight, survival-friendly experience that does not overwhelm the player

The result is a mod that feels useful very quickly. Players do not need to learn a large system before getting value from it. Build a simple network, connect your inventories, open a panel, and everyday storage becomes faster, cleaner, and more enjoyable.
